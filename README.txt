ARMADA website

GitHub Pages:
1. Maak een nieuwe PUBLIC repository aan op GitHub.
2. Pak deze ZIP uit en upload de bestanden EN de map images naar de hoofdmap van de repository (niet de bovenliggende map armada_site).
3. Ga naar Settings > Pages > Build and deployment > Deploy from a branch.
4. Kies branch main, folder /(root), klik Save.
5. Open de gepubliceerde link na enkele minuten.

Alle 30 productfoto’s zijn lokaal inbegrepen. Elke bestelknop opent de eigen opgegeven externe bestelpagina. De website verwerkt zelf geen betalingen.
